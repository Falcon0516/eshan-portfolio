SAATHI: the operator's switchboard (author: Eshan H)
Run: double-click index.html (Chrome or Safari). No internet, no build step.
Keys: arrows/Space/PgUp/PgDn move, P Present/Explore, R Reality Check, T notes, M sound, F fullscreen, Esc back.
Enter replays the current scene's beat. Deep links: index.html#scene-3.
Scene 1: drag the amber cable plug from the lamp into the brass jack.
Scene 2: drag the brass knobs up and down (or use arrow keys when focused).
Explore: router lever and "Pull internet cable" (time x30 tag).
Files: data/facts.js (all text and numbers), js/main.js (shell), js/scenes/scenes.js (7 scenes),
js/sim/flow.js (rope, beads, sparks), css/style.css, assets/ (supplied art, unchanged).
Everything is plain HTML, CSS and JS. System fonts only.
