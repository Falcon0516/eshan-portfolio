USB-TCP BRIDGE  (author: Eshan H)
Run: double-click index.html (Chrome or Safari). Fully offline, no build step.
Keys: Left/Right/Space/PageUp/PageDown scenes, Enter replay beat, P present/explore,
      R Reality Check, T presenter notes, M sound (muted by default), F fullscreen, Esc back/close.
Deep links: index.html#scene-3   Hub entry animation: index.html?from=hub
File map:
  data/facts.js        every on-screen word, number, note and tooltip (edit here)
  js/sim/flow.js       reusable flow engine (paths, beads, gates, queues, particles)
  js/sim/stage.js      world SVG, camera, Plug mascot     js/sim/bridge.js  simulated bridge logic
  js/sim/labs.js       Explore labs                       js/scenes/scenes.js  five Present scenes
  js/ui.js HUD, tooltips, sound   js/main.js boot and keys   css/style.css   look
Everything that animates a process is a SIMULATION (badge on screen).
