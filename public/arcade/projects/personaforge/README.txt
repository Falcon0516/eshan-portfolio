PERSONAFORGE (Eshan H) - toy workshop presentation. Fully offline, no build step.
RUN: double-click index.html (Chrome or Safari). Deep link: index.html#scene-3
KEYS: arrows / Space / PageUp / PageDown move. Enter replays the scene beat. P present/explore.
      R reality check. T presenter notes. M sound (muted by default). F fullscreen. Esc back.
CLICK: right 30% of the screen advances. Objects (bricks, valve, lamp) never advance.
FILES: data/facts.js = ALL text, numbers, notes, tooltips (edit here).
       js/sim/compiler.js = mini prompt compiler, conflicts, scorer. flow.js = flow engine. fx.js = sparks, sound.
       js/scenes/stage.js = the one stage. scenes.js = 8 Present scenes. explore.js = sandbox.
Everything animated is a SIMULATION (badge on screen). Demo blocks are a subset of the real library.
